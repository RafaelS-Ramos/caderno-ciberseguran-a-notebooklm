Caderno de Cibersegurança com NotebookLM
Sobre o Projeto
Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de explorar o uso da Inteligência Artificial como ferramenta de aprendizagem ativa utilizando o NotebookLM.
O tema escolhido foi:
 Cibersegurança
A proposta consistiu em criar um caderno temático utilizando fontes confiáveis, engenharia de prompts e organização de conhecimento para gerar resumos, revisões e materiais de estudo.

Objetivos
Aprender os principais conceitos de cibersegurança;
Entender métodos de autenticação e proteção digital;
Identificar ameaças virtuais comuns;
Utilizar IA para gerar resumos e revisões;
Desenvolver habilidades de curadoria de conteúdo;
Explorar o NotebookLM como ferramenta de estudos.

Engenharia de Prompts
Durante o projeto, diferentes prompts foram utilizados para testar a capacidade da IA em resumir, explicar e organizar conteúdos técnicos.

Prompt 1
Explique os fundamentos da cibersegurança de forma simples para iniciantes.
Resultado
A IA apresentou uma visão geral sobre proteção digital, autenticação, ameaças virtuais e segurança de dados.
Dificuldade
A resposta inicial ficou muito extensa.
Ajuste realizado
Solicitei respostas em tópicos e linguagem simplificada.

Prompt 2
Quais são os ataques virtuais mais comuns atualmente?
Resultado
Foram apresentados ataques como:
Phishing
Ransomware
Engenharia Social
Malware
Dificuldade
Faltaram exemplos práticos.
Ajuste realizado
Pedi exemplos reais e formas de prevenção.

Prompt 3
Explique a diferença entre senha, biometria e token.
Resultado
A IA explicou os diferentes métodos de autenticação e suas aplicações.

Prompt 4
Monte um glossário com os principais conceitos de segurança digital.
Resultado
Foi gerado um glossário útil para revisões futuras.

Miniguia de Estudos
Senha
Método tradicional de autenticação baseado em uma combinação secreta utilizada para acessar sistemas.

MFA (Autenticação Multifator)
Método que utiliza dois ou mais fatores de verificação para aumentar a segurança do acesso.

Biometria
Método de autenticação baseado em características físicas como impressão digital ou reconhecimento facial.

Token
Código temporário utilizado para validação de acesso em sistemas seguros.

Phishing
Golpe virtual que tenta enganar usuários para roubar dados pessoais e senhas.

Malware
Software malicioso criado para danificar sistemas ou roubar informações.
